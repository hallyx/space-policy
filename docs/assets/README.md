# Project-page media

- `space-policy-demo.mp4`: the demonstration video supplied by the project
  owner, transcoded from HEVC to H.264/AAC with the original 61.487-second
  timeline and 1920x1080 resolution. This is presentation media, not a dataset
  or a simulation-scene asset.
- `demo-poster.jpg`: a frame extracted from that video at 45 seconds.
- `method.jpg`: the embedded Figure 3 image extracted from the published
  SpacePolicy paper, without redrawing or changing the figure.

Paper source:
https://rasevents.org/uploads/documents/pdfviewer/c1/0a/235289-1549.pdf
